# OUC 智慧食堂 · 扫码点餐系统

学校食堂的扫码点餐系统：顾客扫桌上的二维码进入点餐页，同桌多人可共用一个购物车拼单；下单后进入后厨看板接单、出餐叫号，支持订单退款审核与每日营收统计。前后端分离，Spring Boot + MyBatis + MySQL，浏览器打开即用，无需安装 App。

## 功能

- **扫码点餐**：每张桌台一个二维码，扫码自动带入桌号
- **同桌拼单**：同一桌共用一辆购物车，多人先后加菜合并成一单
- **后厨接单**：新订单实时进入后厨，接单、制作、出餐状态可切换，新单语音提醒
- **叫号取餐**：出餐后生成取餐号，顾客端可查看叫号进度
- **退款审核**：顾客发起退款，商家审核通过后回写订单状态
- **营收统计**：按日汇总订单数、销售额、退款额
